# A2 - Assignment Two: Medium Template Practice

## Project Goal

This repository contains my medium version of Assignment Two. The goal is to recreate a provided fashion landing page using HTML and CSS, with a focus on layout structure, Flexbox, spacing, typography, positioning, and visual consistency.

The assignment brief can be found here:
https://www.notion.so/A2-Assignment-Two-35aaa7c5a79e807db277dff42d67bc1e

## Reference Design

The design recreated in this project is a winter fashion collection page called **2025 / Winter Drop**.

The page includes:

- a collection heading and navigation label
- a hero section with collection details
- a filter button with an icon
- a featured product image
- product cards for the winter collection
- product names, descriptions, color options, and prices
- product feature highlights
- a footer with navigation links and social icons

## Stage-by-Stage Build Approach

### Stage 1: Understanding the Layout

I first studied the reference design and broke it into its main sections:

- top navigation area
- hero section
- featured product area
- product card grid
- product feature section
- footer

This helped identify the relationships between the larger layout containers and the smaller content elements.

### Stage 2: Building the HTML Structure

The page was divided into clear sections using containers for:

- the main canvas
- navigation and hero content
- product cards
- feature highlights
- footer content

The product information and visual assets are kept inside their relevant sections so the structure remains readable and easy to style.

### Stage 3: Applying Flexbox and Positioning

Flexbox was used to arrange:

- the hero content in columns
- product cards in rows with wrapping
- product details and color options
- feature highlights and separators
- footer navigation and social links

Relative and absolute positioning were used where needed to control the placement of the page sections and their contents.

### Stage 4: Refining Visual Details

The styling was refined with:

- a dark blue winter-themed background
- contrasting white and light-blue text
- Oswald and Scoutie Sans typography
- borders, rounded corners, and separators
- product image sizing and alignment
- spacing and proportions based on the reference

Local product images and SVG icons were added from the `src` directory.

### Stage 5: Final Polish and Review

The final review focused on:

- aligning the hero and product sections
- keeping the product cards consistent
- checking image placement and sizing
- balancing spacing across the page
- reviewing the overall visual similarity to the reference

## Assignment Requirements
